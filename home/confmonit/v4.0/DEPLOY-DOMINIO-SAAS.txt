2. O QUE FAZER NO XANO (passo a passo)
--------------------------------------------------------------------------------

1) Abra o VS Code no workspace core4 (ou painel XanoScript).

2) Faca PUSH destes arquivos (todos de uma vez ou na ordem):
   - tables/126_fp_whitelabel.xs
   - functions/454_fn_fp_whitelabel_montar_fqdn.xs
   - apis/fp_franqueado_pro/2290_fp_whitelabel_salvar_POST.xs
   - apis/fp_franqueado_pro/2309_fp_whitelabel_dominio_remover_POST.xs
   - apis/fp_franqueado_pro/2310_fp_whitelabel_dominio_status_POST.xs

   Comando (se usar extensao Xano): push_all_changes_to_xano

3) Confirme no Xano que a tabela fp_whitelabel tem as colunas novas:
   fqdn, dominio_status, dominio_erro, provisionado_em

4) Confirme que as APIs existem no grupo fp_franqueadoPro:
   - fp_whitelabel_salvar        (POST) — alterada
   - fp_whitelabel_dominio_remover (POST) — nova
   - fp_whitelabel_dominio_status  (POST) — nova

5) Plano necessario: franqueado precisa Pro+ com modulo franqueadopro.saas
   para cadastrar dominio proprio.

--------------------------------------------------------------------------------

Abra PowerShell e execute:

   cd C:\sistemaconfmonit\core4\home\confmonit\v4.0\fp-dominio-provision

         .env

Requisito: Go instalado (https://go.dev/dl/)

6. FLUXO DO CLIENTE (apos deploy)
--------------------------------------------------------------------------------

1) Franqueado acessa: Minha empresa -> White Label
2) Preenche Subdominio (ex: franqueado) + Dominio (ex: redeconfinet.com.br)
3) Clica "Salvar personalizacao"
   -> Xano grava fqdn
   -> Go chama provisionador (Apache + certbot automatico)
   -> Campos de dominio ficam BLOQUEADOS
4) Cliente cria DNS tipo A na hospedagem -> 185.130.61.4
5) Se SSL pendente: clica "Verificar DNS e emitir SSL"
6) Para trocar dominio: botao X vermelho (remove banco + servidor)

--------------------------------------------------------------------------------
7. TROUBLESHOOTING
--------------------------------------------------------------------------------

| Problema                         | Verificar                                      |
|----------------------------------|------------------------------------------------|
| Salvar dominio nao provisiona    | PROVISIONER_URL/KEY no .env do franqueadopro   |
| 401 no provisionador             | API_KEY = PROVISIONER_KEY (mesmo valor)        |
| SSL pendente                     | DNS A apontando para 185.130.61.4; botao SSL   |
| Dominio ja em uso                | Outro franqueado ja usou esse fqdn no Xano     |
| Erro "plano Pro+"                | Assinatura precisa franqueadopro.saas          |
| Apache nao recarrega             | journalctl -u confmonit4fp-dominio-provision   |

Logs:
   journalctl -u confmonit4fp-dominio-provision -f
   journalctl -u confmonit4franqueadopro -f
